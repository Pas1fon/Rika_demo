# РИКА — адаптивный frontend-прототип сайта

Версия 2, 14 октября 2026 года. **29 локальных страниц** с единым оформлением для компьютера и телефона. Официальный логотип и фирменный розовый `#D70D80` сохранены. Собственного backend нет; действующие отслеживание и калькулятор встроены из Courierexe.

Все разделы открываются в новом оформлении. **Личный кабинет** ведёт во внешний сервис `home.courierexe.ru/350/auth/login`. Реальные отслеживание и калькулятор загружаются в рамках страниц из того же внешнего сервиса; для каждого предусмотрено «Открыть отдельно». Телефон и email открывают соответствующее приложение. Переходов на старые страницы РИКА и WhatsApp в основной навигации нет.

## Запуск

**Windows:** откройте `start.cmd`, затем [http://localhost:4173/](http://localhost:4173/). Оставьте окно запуска открытым на время показа. Для остановки нажмите `Ctrl+C` в этом окне. Скрипт ищет установленный Node.js или встроенную среду Codex.

**Без сервера:** откройте `dist/index.html` в современном браузере. Страницы и изображения локальные. Для наиболее предсказуемой демонстрации используйте сервер.

**Через терминал из папки проекта:**

```sh
node server.mjs
```

Либо выполните `npm start`, если npm доступен. Требуется Node.js 18 или новее; **установка пакетов и сборка для запуска не нужны**.

Если порт занят:

```sh
node server.mjs --port 4174
```

Откройте [http://localhost:4174/](http://localhost:4174/). По умолчанию сервер доступен только на вашем компьютере.

## Содержимое

- Главная с быстрыми действиями, услугами, новостями и контактами.
- Каталог услуг и страницы доставки по Казахстану, для бизнеса, эконом-доставки, международных документов и посылок, дополнительных услуг.
- Тарифы, география доставки, информация для клиентов и заключение договора.
- О компании, история, миссия и ценности.
- Новости с поиском и фильтрами и **четыре отдельные статьи**. Перенесены последние публикации на дату проверки, а не весь исторический архив.
- Справочник **24 офисов и ПВЗ в 14 населённых пунктах**, поиск по городу/адресу и фильтр по региону; отдельные страницы Астаны и Алматы.
- Поиск по **23 городам тарифных зон**: 21 город зон 1–2 и Жезказган/Конаев зоны 3. Другие населённые пункты требуют уточнения условий.
- Отслеживание, калькулятор, вызов курьера, оценка качества и карта всех разделов.
- Переключение RU/KZ/EN и мобильное меню. KZ/EN — черновые переводы для демонстрации.

## Действующие сервисы и отдельные демосценарии

На главной и на страницах отслеживания/калькулятора встроены действующие страницы Courierexe:

- [Реальное отслеживание](https://home.courierexe.ru/350/tracking).
- [Реальный калькулятор](https://home.courierexe.ru/350/calculator).

Интерфейс помечает внешний сервис. Данные, которые пользователь вводит **внутри встроенной формы**, передаются напрямую Courierexe. Прототип не подставляет и не переносит данные между локальной демоформой и внешним сервисом. Если встроенная страница не загрузилась, используйте «Открыть отдельно». Работоспособность внешнего сервиса зависит от подключения и самого провайдера.

| Сценарий | Поведение |
| --- | --- |
| Встроенные отслеживание и калькулятор | Действующие внешние сервисы; требуют интернета |
| Локальное демоотслеживание | Доступно отдельно в раскрываемом блоке; `RIKA-DEMO` показывает вымышленный пример |
| Другой номер в локальном демо | Сообщает, что реальный поиск не выполнялся |
| Локальный демокалькулятор | Отдельный раскрываемый блок с условной формулой; не запрашивает реальные тарифы |
| Вызов курьера | Проверяет поля и показывает локальный предварительный просмотр; явно сообщает, что заявка не отправлена |
| Оценка качества | Показывает локальный предварительный просмотр; явно сообщает, что отзыв не отправлен |
| Личный кабинет | Открывает действующий внешний сервис |

Для показа локальных демоформ используйте вымышленные данные. Они не передаются в РИКА или Courierexe. По телефону/email можно самостоятельно связаться с опубликованным офисом.

**Справочная таблица, живой калькулятор и локальное демо различаются.** На странице тарифов приведён справочный снимок пяти строк опубликованных экспресс-тарифов для частных лиц на **14.10.2026**. Встроенный живой калькулятор работает на стороне Courierexe. Отдельный локальный демокалькулятор использует условную формулу: его результат не является ценой РИКА или предложением заключить договор. Снимок таблицы не обновляется автоматически; условия конкретного отправления подтверждает компания.

Справочник контактов и тарифные зоны также различаются: наличие офиса не подтверждает условия любого маршрута, а отсутствие города в справочнике не означает отсутствие доставки.

## Показ руководству — 4 минуты

1. **Главная, 40 секунд.** Покажите логотип, цвет и быстрые действия. Объясните, какие задачи клиент решает с первого экрана.
2. **Переходы, 50 секунд.** Откройте каталог, конкретную услугу, тарифы и географию. Покажите общий дизайн внутренних страниц.
3. **Контент, 50 секунд.** Откройте новость целиком; найдите офис по городу или адресу, затем откройте страницу Астаны либо Алматы.
4. **Сервисы, 60 секунд.** Покажите встроенные действующие отслеживание и калькулятор с подписью Courierexe. Затем раскройте отдельный локальный демоблок, введите там `RIKA-DEMO`, измените параметры демокалькулятора. В форме курьера нажмите «Заполнить пример» и покажите сообщение «Демо-заявка не отправлена».
5. **Телефон и языки, 40 секунд.** Включите ширину 390 px и покажите меню, карточки и формы. Переключите RU/KZ/EN. Обсудите структуру и оформление; подключение курьерских заявок, отзывов и редактуру переводов выделите в следующий этап.

Без интернета доступны локальные страницы и раскрываемые демосценарии. Встроенные действующие сервисы и личный кабинет требуют подключения. Передавайте всю папку проекта либо ZIP-архив, сохраняя структуру файлов.

## Просмотр на телефоне

Быстрый вариант: откройте инструменты разработчика браузера (`F12`), включите режим устройства и выберите ширину 390 px. Для сравнения используйте окно 1440 px.

Для настоящего телефона в той же доверенной Wi-Fi-сети:

```sh
node server.mjs --host 0.0.0.0
```

Узнайте локальный IPv4-адрес компьютера командой `ipconfig` и откройте на телефоне `http://АДРЕС_КОМПЬЮТЕРА:4173/`, например `http://192.168.1.20:4173/`. Если Windows запросит доступ, разрешите его для частной сети. Такой запуск делает прототип доступным устройствам в этой сети; после показа остановите сервер.

## Файлы проекта

```text
rika-prototype/
  dist/          29 HTML-страниц, стили, JavaScript и изображения
  tools/         Исходные тексты и данные для генерации страниц
  preview/       Снимки; версию проверки см. в QA.md
  server.mjs     Локальный статический сервер
  package.json   Команда npm start
  start.cmd      Запуск на Windows
  README.md      Инструкция и сценарий показа
  SOURCES.md     Источники и ограничения
  QA.md          Состояние проверки
```

Готовый `dist/` включён в проект. После изменения исходных текстов в `tools/` страницы можно пересоздать:

```sh
node tools/build.mjs
```

Этот шаг нужен только для редактирования и перезаписывает генерируемые страницы. `npm install` не требуется.
