# РИКА — версия для показа 20 октября 2026

## Запуск
Откройте start.cmd и перейдите по адресу, указанному в окне запуска (обычно http://localhost:4173/). Node.js 18 или новее; установка пакетов не нужна. Можно открыть dist/index.html напрямую.

## Что изменилось
Новый логотип из предоставленного PDF; главная с конкретным предложением и быстрыми действиями; меню для частных лиц и бизнеса; корпоративный раздел и форма запроса условий; вызов курьера с физическим/юридическим лицом и БИН; поиск маршрута с тарифными зонами и офисами; опубликованные корпоративные и эконом-тарифы; полные международные таблицы; документы для договора; постоянная кнопка WhatsApp. Служебные обозначения версии убраны из интерфейса.

## Обращения
Формы готовят текст обращения и ссылку для открытия почтового приложения. Пользователь отправляет письмо самостоятельно. Сайт не регистрирует заказ и не сообщает о состоявшейся отправке. Для города без опубликованного email предлагаются копирование текста и телефон офиса. Корпоративные обращения адресованы tse21@rika.kz. API и CRM не подключены.

## Сервисы
Калькулятор, отслеживание и личный кабинет используют существующий Courierexe. Их работа требует интернета и зависит от провайдера. Вымышленные расчёты и статусы удалены.

## Изменение сайта
Готовые страницы: dist/. Сборка: node tools/build.mjs. Финальные изменения выполняет tools/showcase.mjs; базовые переводы сохранены в tools/base-i18n.js, дополнительные стили и обработчики в tools/showcase.css и tools/showcase.js. Полные опубликованные таблицы хранятся в tools/official-tables.json. Документы: dist/documents/.

## Публикация
Изменения подготовлены локально. Для существующего GitHub Pages обновите содержимое репозитория, сохранив папку rika-prototype/dist/. Доступы, отправка заявок и CRM в эту версию не входят.
